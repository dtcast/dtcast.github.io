# DATACAST Homepage

데이터캐스트 회사소개서와 최근 프로젝트·특허 자료를 반영한 반응형 단일 페이지 홈페이지입니다.

## 확인 방법

`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다. 별도 설치나 빌드 과정은 없습니다.

## 주요 업데이트

- 기존 메시지인 “필요한 것은 숫자가 아닌 메시지”를 중심으로 회사 소개 재구성
- 데이터 수집, AI/NLP, 리서치, 데이터 제품 개발 역량 정리
- 현대차 글로벌 딜러 리뷰 데이터 플랫폼 사례 추가
- 2025년 등록된 CMF 기반 이미지 검색 특허 추가
- 모바일 메뉴, 스크롤 애니메이션, 접근성 및 모션 감소 설정 지원

## 공개 전 확인 권장 항목

- 현대차 프로젝트명과 수치(27개국, 175개 브랜드)의 외부 공개 가능 여부
- 이전 수행 고객사 로고/회사명 공개 범위
- 공식 대표 연락처와 최신 사업장 주소
- 도메인 연결 및 개인정보처리방침 추가 여부

## 배포

- GitHub Pages: `https://dtcast.github.io`
- 연결 도메인: `https://datacast.kr`
- `main` 브랜치에 변경사항을 푸시하면 GitHub Actions가 자동 배포합니다.
- 초안 단계에서는 검색엔진 색인을 막도록 `noindex`와 `robots.txt`가 설정되어 있습니다.
